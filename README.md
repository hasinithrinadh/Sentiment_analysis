# Sentiment_analysis
# 📩 Spam Classification using Qwen

A simple **AI-based Spam Classification** project built using **Python, Hugging Face Transformers, and the Qwen2.5-0.5B-Instruct model**.

The project uses a pre-trained language model to classify messages into two categories:

* 🚨 **Spam**
* ✅ **Not Spam**

The classification is performed using **prompt-based text generation**, where the model is instructed to analyze a message and return only the appropriate label.

---

## 📌 Project Overview

Spam messages are unwanted or potentially harmful messages that may contain advertisements, scams, fake offers, or suspicious links.

This project demonstrates how a **Large Language Model (LLM)** can be used as a simple spam detection system without training a separate machine-learning classifier.

The model receives a prompt such as:

```text
You are a spam detection system.

Classify this message:

"Congratulations! You've won a $1000 gift card, click here to claim now!"

Possible labels:
1. Spam
2. Not Spam

Answer with ONLY the label.
```

The model then generates a classification such as:

```text
Spam
```

## 🔄 How the Project Works

The complete workflow is:

```text
User Message
     ↓
Classification Prompt
     ↓
Qwen2.5-0.5B-Instruct
     ↓
Text Generation
     ↓
Extract Generated Response
     ↓
Spam / Not Spam
```

### Step 1: Import Pipeline

The Hugging Face Transformers pipeline is imported:

```python
from transformers import pipeline
```

### Step 2: Load the Model

The Qwen model is loaded using:

```python
classifier = pipeline(
    "text-generation",
    model="Qwen/Qwen2.5-0.5B-Instruct"
)
```

Here, the `text-generation` pipeline allows the model to generate a response based on the given prompt.

### Step 3: Create the Classification Function

The function:

```python
def spam_classification(text):
```

takes a message as input.

### Step 4: Create the Prompt

The message is inserted into a prompt that tells the model exactly what task to perform.

The model is given two possible labels:

```text
1. Spam
2. Not Spam
```

It is also instructed:

```text
Answer with ONLY the label.
```

This helps reduce unnecessary generated text.

### Step 5: Generate the Prediction

The model processes the prompt:

```python
output = classifier(
    prompt,
    max_new_tokens=5,
    do_sample=False
)
```

### Parameters

**`max_new_tokens=5`**

Limits the number of new tokens generated by the model.

Since the expected answer is very short, only a few tokens are needed.

**`do_sample=False`**

Disables random sampling and makes the generation deterministic for the same input and model state.

### Step 6: Extract the Generated Text

The generated response is obtained using:

```python
response = output[0]["generated_text"]
```

The original prompt is removed:

```python
generated = response[len(prompt):].strip()
```

This leaves the model's generated classification.

### Step 7: Display the Result

The program prints:

```text
--------------------------------
Text  : <message>
Label : <classification>
--------------------------------
```

## 🔑 Key Concepts

### 1. Hugging Face Transformers

Transformers is a popular library for working with pre-trained transformer-based models.

In this project, it is used to load and run the Qwen model.

### 2. LLM

A **Large Language Model (LLM)** is an AI model trained to understand and generate human language.

Here, the LLM is used to perform classification through instructions rather than traditional supervised training.

### 3. Prompt Engineering

The project uses a carefully written prompt to tell the model:

* What role it should perform
* What message to classify
* Which labels are allowed
* What format the answer should have

### 4. Zero-Shot Classification

The model is not given training examples in the prompt.

Instead, it receives the task description and directly classifies the message.

This is an example of **zero-shot prompting**.

### 5. Text Generation

Although the task is classification, the project uses a **text-generation pipeline**.

The model generates the classification label as text.

## ⚠️ Limitations

This project uses an instruction-following LLM for classification, so it may not always produce the expected label.

Possible limitations include:

* The model may generate additional text despite the instruction.
* Sarcastic or ambiguous messages may be difficult to classify.
* Marketing messages are not always spam.
* Classification accuracy depends on the model's understanding of the prompt.
* The model was not specifically fine-tuned for spam detection.
* The generated response should ideally be validated before treating it as a final label.

For a production-level spam detection system, a dedicated classification model or a fine-tuned model could be used.
